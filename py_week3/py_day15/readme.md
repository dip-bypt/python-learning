# LangChain Fundamentals - Day 15

## Overview
This project demonstrates the fundamentals of using LangChain with LLMs (Large Language Models) to build a polite sentence rewriter. It includes a FastAPI-based web API and a practical example of using LangChain's modern composition style.

---

## Learning Topics Covered
- **LangChain Overview**
- **What are LLMs & Chains?**
- **Installing and using `langchain`, `openai`, and `python-dotenv`**
- **Practical Task:** Using LLMChain (and modern LangChain composition) to rewrite a sentence politely

---

## Practical Task Details
- **Task:** Use an LLM to rewrite a sentence in a more polite way.
- **Prompt Template:**
  - `Rewrite the following sentence politely: {sentence}`
- **Modern LangChain Usage:**
  - The code uses the new composition style: `chain = prompt | llm`
  - Example: Input "Send me the report now!" → Output: Polite version generated by the LLM
- **API:**
  - FastAPI app exposes a `/rewrite` endpoint to rewrite any sentence politely via POST request.

---

## File Structure & Details

### main.py
- Loads environment variables from `.env` using `python-dotenv`.
- Initializes an OpenAI LLM with the API key from `.env`.
- Defines a polite rewriting prompt and composes it with the LLM.
- Provides both a script example and a FastAPI web API for polite rewriting.

### .env
- Stores sensitive environment variables (e.g., `OPENAI_API_KEY`).
- **Example:**
  ```env
  OPENAI_API_KEY=your_openai_api_key_here
  ```
- **Note:** Never share your real API key publicly.

### requirement.txt
- Lists all required Python packages:
  - `fastapi`, `uvicorn`, `langchain`, `openai`, `python-dotenv`, `langchain_community`, `langchain-openai`

---

## How to Run
1. **Install dependencies:**
   ```bash
   pip install -r requirement.txt
   ```
2. **Set up `.env` file:**
   - Add your OpenAI API key as `OPENAI_API_KEY=...`
3. **Run the API:**
   ```bash
   uvicorn py_day15.main:app --reload
   ```
4. **Test the API:**
   - Use `/rewrite` endpoint with a POST request containing `{ "sentence": "Your sentence here" }`.
